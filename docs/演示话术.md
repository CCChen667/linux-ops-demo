# 60 秒项目演示话术

“这是我在 Ubuntu 24.04 和 Nginx 上完成的一个完整部署演示。网页本身只是交付的一部分，重点在后面的运维流程。”

1. 打开 `http://localhost:8088`，展示网页和实时健康状态。
2. 执行 `sudo bash scripts/health-check.sh`，说明它同时检查配置、服务和 HTTP 响应。
3. 展示 `/srv/linux-ops-demo/releases`，说明每次部署都会产生独立版本。
4. 修改网页后再次部署，证明新版本可以发布。
5. 执行回滚脚本，说明出现问题时可以恢复上一个版本。
6. 展示 `D:\Codex\backups\linux-ops-demo` 中的备份和 SHA-256 文件。

最后可以这样总结：

> 我能处理小型 Linux 网站的部署、Nginx 配置、服务检查和备份回滚。这个演示项目里的脚本都实际运行过，可以根据你的服务器环境调整。

不要声称这是付费客户案例；称它为“可复现的个人交付演示”更诚实，也足够证明能力。

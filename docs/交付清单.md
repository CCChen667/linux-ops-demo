# Linux 网站部署交付清单

## 接单前需要向客户确认

- 服务器系统、IP 和登录方式；只接受客户主动提供的合法授权。
- 网站类型：纯静态、PHP、Node.js，还是需要反向代理。
- 域名是否完成实名认证与解析，是否需要 HTTPS。
- 现有网站是否允许停机，必须先确认备份和回滚窗口。
- 明确本次包含什么、不包含什么，以及售后时间。

## 本演示项目可交付内容

- 一套响应式静态展示站。
- Nginx 独立站点配置及安全响应头。
- 原子发布脚本，默认保留最近 5 个版本。
- 健康检查、备份和回滚脚本。
- HTTP 状态、Nginx 配置、服务状态三项验收记录。

## 验收命令

```bash
sudo nginx -t
systemctl is-active nginx
curl -i http://127.0.0.1:8088/health
sudo bash scripts/health-check.sh
```

预期结果：Nginx 配置通过、服务状态为 `active`、健康接口返回 HTTP 200 和 `status: ok`。

## 新手首单建议边界

可以先承接范围清楚、可在一天内完成的小任务，例如：

- Nginx 静态网站部署与故障排查。
- 域名解析、HTTPS 配置与到期检查。
- Linux 磁盘、端口、服务和日志基础排查。
- 简单备份脚本和定时任务。

不要在经验不足时承诺数据库恢复、生产服务器安全加固、无停机迁移或重大故障抢修。
